# Content Moderation CMS · Digilabour
> Dashboard de Gestão de Dados e Insights da Série de Entrevistas "Quem Modera o Mundo?".

Este repositório contém a plataforma de curadoria e análise qualitativa desenvolvida para a série de entrevistas sobre moderação de conteúdo do **Digilabour**. A ferramenta combina georreferenciamento de pesquisadores globais com um sistema de gestão de transcrições inspirado em ferramentas de elite como Sonix e LoopPanel.

## 🚀 Funcionalidades Principais

- **Mapa Mundi Interativo:** Visualização da rede global de pesquisadores (UCLA, Microsoft Research, DAIR, UFBA, etc.) com filtros por eixos temáticos.
- **Deep Search (Insight Engine):** Busca semântica que varre simultaneamente perfis, bibliografias e o corpo das entrevistas, destacando trechos relevantes.
- **Diarização Editorial:** Sistema de transcrição que separa visualmente as falas de entrevistadores e entrevistados, otimizando a leitura acadêmica.
- **Eixos Temáticos:** Categorização dinâmica por Trabalho & Saúde, Governança Digital, Vieses Algorítmicos e Sul Global.
- **Offline-First:** Persistência automática no navegador via LocalStorage, garantindo que nenhum dado seja perdido durante o trabalho de campo.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5 semântico, CSS3 (Design Editorial Minimalista).
- **Mapas:** [Leaflet.js](https://leafletjs.com/) com tiles CartoDB.
- **Engine de Busca:** Algoritmo de Highlighting e Snippet extraction em JavaScript puro.

## 📂 Como Utilizar

1. Faça o download do arquivo `index.html`.
2. Abra em qualquer navegador moderno.
3. Utilize a aba **Pesquisadores** para gerenciar biografias e a aba **Episódios** para colar e editar as transcrições das entrevistas.
4. Para salvar um backup externo, utilize o botão **Exportar** no topo da página.
